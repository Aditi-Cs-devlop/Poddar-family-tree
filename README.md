# Poddar Family Tree 🌳

An interactive multi-generation family tree built using **HTML, CSS, and JavaScript**.

The project presents a large family tree inside a contained interactive window, making it easier to explore relationships without creating an extremely large scrolling webpage.

## ✨ Features

- Expandable and collapsible family branches
- Zoom in / zoom out
- Drag and pan across the tree
- Mouse-wheel zoom
- Responsive design for different screen sizes
- Automatic tree centering
- Interactive family member cards
- Clean and simple visual representation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Responsive Web Design

## 🚀 How to Use

1. Open the HTML file in a modern web browser.
2. Click on a family member to reveal their next generation.
3. Click again to collapse the branch.
4. Use the **+ / −** buttons or the mouse wheel to zoom.
5. Drag the tree to move around the family structure.
6. Use the **Home (⌂)** button to reset the view.

## 🎯 Purpose

The project was created to provide a **simple and interactive way to visualize a large multi-generation family tree** while keeping the interface contained, navigable, and user-friendly.
